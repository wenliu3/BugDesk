BugDesk · Bug 提交助手 1.2.0
======================

源码版需要 Windows 和 Python 3.11+。在项目目录运行 python app.py，或双击「启动开发版.cmd」。自行打包的便携版双击 BugDesk.exe，不需要另装 Python。

1. 先体验示例
点击「先试试示例数据」，查看三条合成 Bug。示例不能提交到禅道。

2. 整理自己的 Bug
按日期建立总文件夹，每个直接子文件夹对应一条 Bug，名称作为初始标题。将截图、视频和其他证据放在对应的子文件夹中。选择日期目录并扫描后，补齐前置条件、复现步骤、实际结果和预期结果。工具不会改动原始证据，也不会凭空补造事实。

文件夹改名或整个日期目录移动后，扫描前可在「关联原来的 Bug」中选择对应旧记录，保留编辑后的标题、报告、来源和禅道编号，并重新读取附件。默认作为新 Bug，不会自动按相似标题关联；整批搬迁可明确选择旧目录后匹配同名记录，再核对确认。

3. 公共设置与单独设置
公共设置填写产品、项目、执行、模块、影响版本、指派人、反馈者等。连接禅道后可以读取部署中的菜单，版本支持多选。个别 Bug 不同的类型、严重程度、优先级、指派人和发生概率，在编辑区右上角「本条设置」中修改；可一键恢复公共配置。修改事实或设置后需要重新审核。

4. 粘贴用例与 WorkBuddy
「更多」中的「粘贴用例」支持 HTML 表格、TSV 和多行单元格，先识别字段，再核对每条用例对应的 Bug。默认仅补空白；覆盖已有内容需要明确勾选。

可选 WorkBuddy 整理：从 https://github.com/wenliu3/BugDesk/releases/latest 下载并安装 BugDesk-WorkBuddy-Skill-1.2.0.zip 配套技能，开启 60 分钟本机连接，复制当次任务并附上允许发送的失败用例。WorkBuddy 会将同一 Bug 的多条用例整理成一份报告；相同流程只换输入时使用公共步骤加完整输入清单。等建议回传后，逐条核对报告和全部来源，再点击「导入已核对 Bug」。悬停只预览，点击才选用。不自动审核或提交。

「导入前后对比」显示当前补空白或覆盖模式下的差异，覆盖已有正文前还会集中确认。导入后可点击「撤销上次导入」，跨重启保留最近一次有变化的导入；之后如已修改目标内容、设置或附件，或尝试提交，将拒绝撤销以保留后续操作。撤销后重新审核。

完整图解位于主界面「更多」→「WorkBuddy 使用说明」。连接过期、切换批次或关闭工具后，需要重新开启并复制任务。

5. 预览、审核与提交
在「附件」中预览证据，扫描到的附件会全部随 Bug 上传。不需要的文件请从原始文件夹移除后重新扫描。在「提交预览」中检查完整报告，再审核当前 Bug 或批量审核。连接自己的禅道后可提交已审核条目。连接器基于 18.11 经典页面接口；不同部署的定制字段、认证和权限需要实际验证。首次实际提交仅一条，确认编号和附件后再批量操作。结果不确定时先到禅道核对，不重复创建。

图片、视频和音频直接预览；PDF 保留浏览器的翻页和缩放工具。日志和文本、CSV / TSV、XLSX 表格、DOCX / PPTX 正文以及 ZIP 文件清单可在本机查看，Office 为内容预览，不还原全部排版。预览不执行脚本、公式或宏。按 Esc、点击关闭按钮或窗口外部退出；不支持的格式请在原始文件夹中用本机应用打开。

6. 导出和关闭
「更多」→「导出与备份」可生成 Markdown、CSV、JSON；JSON 可用于迁移。内容自动保存，Ctrl+S 立即保存，Ctrl+Enter 审核当前 Bug，Alt+↑/↓ 切换相邻 Bug。使用「更多」→「保存并关闭工具」结束程序。

7. 外观与数据
右上角月亮/太阳按钮切换浅色与深色主题，浏览器会记住手动选择。源码开发启动器使用 .local，直接运行默认使用 Windows 本地应用数据目录。便携版带 portable.flag 时使用旁边的 BugDesk-data。升级时保留自己的数据目录。

服务只监听本机。禅道密码和登录会话只保存在内存。AI 整理会按使用的客户端处理你提供的测试资料，请确认允许发送。不要把数据目录、真实 Bug、连接文件或导出备份上传到公开仓库。
